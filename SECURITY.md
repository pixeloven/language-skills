# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting:
open this repository's **Security** tab and choose **Report a vulnerability**.
Do not open a public issue, pull request or discussion for a security problem.

Include the affected skill or file, the release or commit, and what an agent or
project could be led to do as a result.

## Supported versions

language-skills ships as tagged releases. Fixes land on `main` and go out in the
next release; only the latest release is supported. Upgrade to it rather than
expecting a patch to an older one.
